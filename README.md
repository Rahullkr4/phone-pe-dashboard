# 📊 PhonePe Transaction Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** built to analyze PhonePe's transaction and user data. The dashboard provides insights into transaction trends, transaction value, user growth, and geographical performance.

The objective of this project is to transform raw data into meaningful business insights that can help understand **customer adoption, transaction behavior, and regional performance**.

---

## 🎯 Business Objectives

* Analyze overall transaction performance.
* Identify monthly and yearly transaction trends.
* Compare transaction volume and transaction value across states.
* Analyze user growth and adoption patterns.
* Identify high-performing and low-performing regions.
* Build an interactive dashboard for easy business analysis.

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Excel / CSV** – Data source
* **GitHub** – Project documentation and version control

---

## 📂 Dataset

The dataset contains information related to PhonePe transactions and users across different Indian states and time periods.

Key attributes include:

* State
* Year
* Quarter / Month
* Transaction Count
* Transaction Amount
* User Count
* User Engagement
* Geographic information

> **Note:** The dataset is used for educational and analytical purposes.

---

## 📊 Dashboard Features

### 1. Executive Overview

Provides a high-level view of the overall business performance through:

* Total Transactions
* Total Transaction Value
* Total Users
* Average Transaction Value
* Growth Trends

### 2. Transaction Analysis

Analyzes transaction behavior using:

* Transaction volume trends
* Transaction value trends
* Monthly/quarterly performance
* Transaction type/category analysis
* Year-over-year comparisons

### 3. User Analysis

Provides insights into:

* User growth
* User adoption
* User engagement
* State-wise user distribution
* Growth patterns over time

### 4. Geographic Analysis

Uses maps and state-level visualizations to identify:

* Top-performing states
* Low-performing states
* Regional transaction patterns
* Regional user adoption

## ⚙️ Data Preparation

The data preparation process included:

1. Importing raw datasets into Power BI.
2. Removing duplicate and inconsistent records.
3. Handling missing values.
4. Standardizing data types and formats.
5. Creating calculated columns where required.
6. Building relationships between datasets.
7. Creating DAX measures for KPIs.
8. Designing the final interactive dashboard.
